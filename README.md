# Gemini Skill Generator

**Free online tool:** https://deejay2589.github.io/gemini-skill-generator/

Turn a Gemini Gem into a downloadable, spec-compliant **SKILL.md** file — or build a new skill from scratch with a simple form. No sign-up, runs entirely in your browser, nothing is uploaded or stored.

## Why now?

Google is replacing Gems with Skills. Personal Gems became read-only on **November 17, 2026** and will be **deleted on December 17, 2026**. Convert yours before they are gone — the generated SKILL.md works in Gemini, Claude, ChatGPT and Copilot.

## Features

- Two modes: build a skill from scratch, or migrate an existing Gem
- Validates skill names (lowercase, hyphens) and file structure as you type
- Migration mode warns about the 100MB attachment limit (largest files are dropped first)
- One-click copy or download of the finished SKILL.md

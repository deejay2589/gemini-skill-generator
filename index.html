What is a SKILL.md file?

  
A SKILL.md file is a small Markdown file in the open Agent Skills format. It has a short header (the skill's name and description) followed by plain-language instructions that tell an AI assistant how to do one specific job — the same role a Gem's instructions played, but in a portable file you own.

  
Because the format is open (it was handed over to the Linux Foundation in October 2026), the same SKILL.md file works across tools: upload it to Gemini as a Skill, or use it in Claude, ChatGPT and Copilot. One file, every assistant — no lock-in to a single app.


  
Why migrate? Gems are going away

  
Google announced on September 30, 2026 that Skills replace Gems in Gemini. For personal accounts, Gems become read-only on November 17, 2026 and are permanently deleted on December 17, 2026. Google will auto-convert your Gems into Skill drafts, but anything over the 100 MB per-Skill file limit gets trimmed — largest attachments first. Rebuilding your best Gems as clean SKILL.md files with this generator takes a minute and gives you a backup that also works outside Gemini.

FAQ

  

    What's the difference between a Skill and a Gem?
    
Skills are Google's replacement for Gems in Gemini. A Gem lived only inside your Gemini account; a Skill is based on a portable SKILL.md file you can download, back up and reuse. Personal Gems become read-only on November 17, 2026 and are deleted on December 17, 2026, so the time to move is now.

  

  

    What exactly is SKILL.md?
    
SKILL.md is a Markdown file in the Agent Skills format: a name + description header, followed by instructions in plain language. You can upload it directly to Claude, and the same file works in Gemini, ChatGPT and Copilot.

  

  

    Where do I use the file this generator creates?
    
Download it, then upload it where your assistant accepts skills: create a Skill in Gemini, or add it in Claude, ChatGPT or Copilot. The file is identical for all of them — generate once, use everywhere.

  

  

    Will I lose my old Gems?
    
Google auto-converts Gems into Skill drafts, but each Skill is capped at 100 MB of files, and oversized attachments are dropped from largest to smallest. If your Gems have important attachments, download them before December 17, 2026 — and pasting your Gem's instructions into the Migrate tab above gives you a clean, portable copy regardless.
